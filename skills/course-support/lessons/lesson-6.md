## Browser experiments

Prefer [in-browser speech](https://huggingface.co/spaces/Xenova/text-to-speech-client), [background removal](https://xenova-remove-background-webgpu.static.hf.space/index.html) or [depth/parallax](https://huggingface.co/spaces/Xenova/depth-anything-web). These run inference in the browser and avoid dependence on a shared server GPU quota, but still need downloads, compatible devices and appropriate licenses. The RMBG model has noncommercial restrictions; skip it if the actual use is not covered. Speech is the main follow-along; choose one of the visual experiments as an alternative.

[LivePortrait](https://huggingface.co/spaces/KlingTeam/LivePortrait), [ACE-Step](https://huggingface.co/spaces/ACE-Step/Ace-Step-v1.5) and [Wan S2V](https://huggingface.co/spaces/Wan-AI/Wan2.2-S2V) are instructor candidates, not guaranteed free student jobs. Preflight them twice with the actual account and classroom network. Do not describe sample playback or an available interface as successful live generation.

## Local video exercise

Install `--lesson 6` with the shared setup. Open the [local-promotion-video guide](../../local-promotion-video/README.md). Preinstall its pinned dependencies and render a short video on each learner's machine before class; no course backend is required.

Use about 40 minutes: clarify the real product and one message (5), arrange a few timed scenes (5), adapt screenshot/text scenes (10), preview and request a revision (7), render (8), inspect/export (5). Screenshots and readable text are sufficient for a silent draft; permitted narration/music are optional inputs. Deliver MP4 plus editable project and sources. A content-generation API, paid provider and shared GPU service are not prerequisites.

For Campaign, use one two-week Todo example: a teaser, product page and video, a useful scenario/tutorial, optional creator/partner sharing, then review. Distinguish awareness/interaction from visits/signups. Keep brand case studies in instructor notes rather than adding slides.
