# Sources and runtime scope

This skill, copy helper, validation and starter scenes are original handbook work. They use public Remotion APIs; no private video-wrapper implementation or upstream skill prose is redistributed here.

- [Remotion compositions](https://www.remotion.dev/docs/composition)
- [Remotion renderer](https://www.remotion.dev/docs/renderer)
- [Remotion bundler](https://www.remotion.dev/docs/bundle)
- [Remotion licensing](https://www.remotion.dev/license)
- [Hugging Face ZeroGPU](https://huggingface.co/docs/hub/main/spaces-zerogpu)

The starter pins Remotion packages to 4.0.532 and React to 19.2.0. Runtime license, font/media rights, optional model weight licenses and provider output terms are distinct. The absence of an API key does not establish commercial rights or make hardware/Codex access cost-free.

The starter uses an explicitly supplied installed browser and local assets. It is a local build/render helper, not an OS sandbox or a security boundary for arbitrary project code. Keep any existing project's protection and renderer choices intact. A different wrapper's Linux isolation contract is not modified by using this independent native starter.

The example is fictional and contains no customer records, face images, music or product URLs. The default output is silent. Supply only assets the user is authorized to use, and retain their origin and intended use in the project's sources.md.
