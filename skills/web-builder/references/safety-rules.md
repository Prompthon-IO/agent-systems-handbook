# Safety rules

Never replace an existing stack, overwrite edited starter files, run unreviewed package scripts, collect real form data, or publish from this skill. HTML text is escaped. The starter is not a general natural-language design compiler; Codex implements unsupported designs in the existing-stack workflow.

Use only the authorized organization/workspace. Honor API refusal, scope mismatch, conflict and reset gates. Never persist secrets or absolute personal paths. Dry runs cannot authorize a later external action by themselves.
