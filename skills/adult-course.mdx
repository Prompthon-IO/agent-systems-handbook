The adult course separates twelve capabilities into four three-step lessons:

| Lesson | Skill boundaries |
| --- | --- |
| 2 — Computer and materials | Organize files → Understand sources → Automate tool steps |
| 3 — Websites | Build a local site → Test behavior → Deploy a preview |
| 4 — Business data | Structure a dataset → Operate CRM objects → Analyze evidence |
| 5 — Media and AEO | Plan content → Distribute through canonical Social operations → Discover visibility gaps |

Use the [course package guide](https://github.com/Prompthon-IO/agent-systems-handbook/blob/develop/skills/course-support/README.md) for the packages and labs available on the integration branch. It includes a copy-based Codex installer, synthetic fixtures, English and Simplified Chinese exercises, modification tasks and reset instructions. Existing organizer, knowledge-capture and Social packages are extended rather than duplicated.

```bash
python3 skills/course-support/scripts/setup_course_skills.py --lesson 2
python3 skills/course-support/scripts/seed_demo.py
```

The public/offline mode stores course records locally. The intended instructor-provisioned course mode uses a scoped Prompthon API and server-side Neon/PostgreSQL. The [backend dependency](https://github.com/Prompthon-IO/agent-systems-handbook/blob/develop/skills/course-support/references/backend-dependency.md) must be completed and verified by the Web App owner before remote classroom use. This page does not claim that a production course service has been deployed.

Keep one job per skill, preview consequential actions, preserve original files, and verify persisted state by reading it back. Never distribute production DB credentials or allow students to publish to real Social channels from a classroom fixture.
